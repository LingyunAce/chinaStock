# 多角度技术信号扫描指南（金叉/死叉/多空力道）

> **定位**：本文档是 SKILL.md 的 **L3 层补充材料**，提供"全维度金叉/死叉信号扫描"的标准化分析框架。
>
> **使用场景**：当用户问"有没有金叉信号"、"是不是死叉了"、"什么时候能买"、"多空力道如何"、"技术面如何"时使用。
>
> **核心理念**：单一指标易误判，**多指标交叉验证**才能提高胜率。本文档把 10+ 主流技术指标系统化扫描，输出统一的多空判断。

## 一、查询命令

只需一条命令即可拉取所有金叉相关数据：

```bash
westock-data technical sh600198 --group all
# 或指定关键分组
westock-data technical sh600198 --group ma,macd,kdj,rsi
```

返回字段覆盖：均线（ma）、MACD、KDJ、RSI、BOLL、BIAS、WR、DMI、CCI、TRIX、PSY、OBV、SAR、AR/BR 等。

## 三、标准化扫描流程（4 步法）

### Step 1：拉取全指标
```bash
westock-data technical <代码> --group all
```

### Step 2：填入"金叉扫描矩阵表"

按以下模板填写（**必须用 Markdown 表格输出**）：

```markdown
| 指标 | 快线值 | 慢线值 | 状态 | 距离金叉 |
|---|---|---|---|---|
| MACD | DIF: x.xx | DEA: x.xx | 🔴 死叉 / 🟢 金叉 / 🟡 接近 | DIF 需上穿 x.xx |
| KDJ | K: xx.xx | D: xx.xx | 🔴/🟢/🟡 | 差距 x.xx |
| MA5/MA10 | x.xx | x.xx | 🔴/🟢/🟡 | - |
| MA5/MA20 | x.xx | x.xx | 🔴/🟢/🟡 | - |
| EMA12/EMA26 | x.xx | x.xx | 🔴/🟢/🟡 | - |
| DMI (PDI/MDI) | PDI: x.xx | MDI: x.xx | 🔴/🟢/🟡 | - |
| TRIX/TRIXMA | x.xx | x.xx | 🔴/🟢/🟡 | - |
| PSY/PSYMA | x.xx | x.xx | 🔴/🟢/🟡 | - |
```

**状态判定规则**：
- 🟢 **金叉**：快线 > 慢线，且差距 > 0
- 🔴 **死叉**：快线 < 慢线
- 🟡 **接近金叉**：快线 < 慢线，但差距 < 慢线绝对值的 10%，且短期 1-3 日内可能转向

### Step 3：辅助超买/超卖区域判断

金叉/死叉的**有效性**需要结合超买/超卖区判断：

| 指标 | 超买阈值 | 超卖阈值 | 含义 |
|---|---|---|---|
| KDJ-J | > 100 | < 0 | 极度超买/超卖 |
| KDJ-K | > 80 | < 20 | 超买/超卖 |
| RSI6 | > 80 | < 20 | 超买/超卖 |
| RSI12 | > 70 | < 30 | 超买/超卖 |
| WR6 | < 20 | > 80 | 超买/超卖（注意 WR 数值反向） |
| CCI_14 | > 100 | < -100 | 强势/弱势 |
| BIAS6 | > 8% | < -8% | 短期超买/超卖 |
| BIAS24 | > 15% | < -15% | 中期偏离过大 |

> **🎯 黄金原则**：**超卖区的金叉** > 中位区的金叉 > 超买区的金叉
> 例如 KDJ 在 J<20 时金叉，比 J=50 时金叉强度高 3 倍

### Step 4：多空力道综合评级

按"金叉信号数量"和"指标权重"打分：

| 金叉数量 | 看多评级 | 操作建议 |
|---|---|---|
| 0 个 | 🔴 极弱 | 规避或卖出 |
| 1-2 个（弱指标如 PSY/KDJ） | 🟡 中性偏弱 | 观察 |
| 3-4 个（含 MACD 或 DMI 之一） | 🟢 中性偏强 | 试探建仓 |
| 5-6 个（多指标共振） | ⭐ 强 | 加仓 |
| 7-8 个（全面金叉） | ⭐⭐ 极强 | 重仓持有 |

⚠️ **权重提示**：
- **MACD + DMI + MA20** 三大权重指标，任一金叉 = 2 分
- 其他次要指标，金叉 = 1 分
- 综合 ≥ 5 分才算"强买信号"

## 四、典型场景识别

### 🎯 场景 A：经典强势金叉（最佳买点）
```
✅ MACD 金叉 + 红柱出现
✅ KDJ 金叉（J 在 20-50 区间）
✅ MA5 上穿 MA10
✅ PDI > MDI 且 ADX 上升
✅ 价格站上 BOLL 中轨
✅ 成交量放大 1.5 倍以上
```
**含义**：趋势翻转初期，进入强势区间，可中线持有。

### 🎯 场景 B：超卖反弹金叉（短线博弈）
```
🟡 KDJ 在 J<20 时金叉
🟡 RSI6 < 30 后回升
🟡 BIAS24 < -10% 后修复
🔴 但 MACD 仍死叉、均线空头排列
```
**含义**：超跌反弹机会，**仅适合短线博弈**，目标位通常是 MA10 或 MA20，**不建议中线持有**。

### 🎯 场景 C：死叉强烈预警（卖出信号）
```
🔴 MACD 死叉 + 绿柱扩大
🔴 KDJ 死叉（J 从 >100 回落）
🔴 MA5 下穿 MA10
🔴 PDI < MDI 且 ADX 上升（空头力道增强）
🔴 价格跌破 BOLL 中轨
```
**含义**：趋势翻转向下，**应果断减仓或清仓**。

### 🎯 场景 D：假金叉陷阱（最危险）
```
🟢 KDJ 在 J>80 时金叉（高位钝化）
🟢 MA5/MA10 金叉但量能萎缩
🔴 MACD 仍在零下且 DEA 向下
🔴 DMI 中 MDI 仍 > PDI
```
**含义**：**高位假突破**，主力诱多出货，**不可追入**。

## 六、特殊指标补充

### SAR（停损转向指标）
- 当**收盘价 > SAR**：多头格局
- 当**收盘价 < SAR**：空头格局
- SAR 翻转 = 趋势反转预警

### OBV（能量潮）
- OBV 与价格同步上升 = 量价齐升（强势）
- OBV 下降而价格上升 = 价升量缩（背离，警惕）
- OBV 上升而价格下降 = 量价底背离（反弹预兆）

### AR/BR（人气与意愿指标）
- AR 在 80-150 = 正常区间；> 180 超买；< 50 超卖
- BR 在 70-150 = 正常；BR < AR 且都低位 = 底部信号
- BR 突然大涨而 AR 不涨 = 警惕诱多

### ADX（趋势强度）
- ADX < 20：无趋势（震荡市）
- ADX 20-40：趋势形成中
- ADX > 40：强趋势
- 在 ADX 上升时的金叉/死叉，**有效性最高**

## 七、易犯错误清单

❌ **错误 1**：只看 KDJ 金叉就买入
- 正确：必须同时确认 MACD 不在死叉持续期 + 均线非完全空头

❌ **错误 2**：高位 KDJ 金叉视为买入信号
- 正确：J > 80 的金叉是**钝化陷阱**，应警惕主力诱多

❌ **错误 3**：把 PSY/AR/BR 等次要指标作为主信号
- 正确：这些是辅助指标，**绝不能单独作为买入依据**

❌ **错误 4**：忽视成交量验证
- 正确：任何金叉必须**放量配合**才有效（建议放量 1.3-2 倍）

❌ **错误 5**：把"接近金叉"当作"已金叉"操作
- 正确：信号未确立前的"预测"，胜率不超过 50%，需等确立

## 九、术语速查

| 术语 | 解释 |
|---|---|
| 金叉 | 短期线上穿长期线，看多信号 |
| 死叉 | 短期线下穿长期线，看空信号 |
| 钝化 | 指标长期处于超买/超卖区，敏感性失效 |
| 背离 | 价格与指标走势相反，预警反转 |
| 共振 | 多个独立指标同时给出相同信号 |
| 假突破 | 突破后未能站稳，回落 |
| 量能确认 | 信号必须配合放量才有效 |
| 顶背离 | 价创新高但指标未创新高（看空） |
| 底背离 | 价创新低但指标未创新低（看多） |
